# Simple Audio Amplifier Using 2N6292 Transistor

## Overview
This repository contains the presentation slides, circuit schematic, and hardware implementation details for a **Single-Transistor Audio Amplifier**. The project amplifies low-power audio signals (e.g., from a mobile phone) to drive an 8Ω/10W speaker using a single 2N6292 NPN power transistor.

## ⚡ Working Principle
1. **Input:** Weak audio signal enters via the 3.5mm audio jack.
2. **DC Blocking:** The 22µF capacitor removes DC offset from the input signal.
3. **Amplification:** The 2N6292 NPN transistor uses energy from the 9V battery to amplify the base current, boosting the signal at the collector-emitter terminal.
4. **Output:** Amplified current drives the speaker cone to produce audible sound output.
